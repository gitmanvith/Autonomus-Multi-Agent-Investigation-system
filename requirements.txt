## 2. React and Jest dependencies

These must go into your frontend's `package.json`, not Python's requirements file.

```bash
npm install react react-dom axios
npm install react-router-dom lucide-react recharts
npm install socket.io-client

npm install -D jest
npm install -D jest-environment-jsdom
npm install -D @testing-library/react
npm install -D @testing-library/jest-dom
npm install -D @testing-library/user-event
```

## 3. Installation commands

Run these commands on Windows:

```bash
# Create virtual environment
python -m venv venv

# Activate environment
venv\Scripts\activate

# Upgrade pip
python -m pip install --upgrade pip

# Install dependencies
pip install -r requirements.txt

# Install Chromium for Playwright
playwright install chromium
```

## 4. Environment variables

Create a `.env` file:

```env
OPENAI_API_KEY=your_openai_api_key
TAVILY_API_KEY=your_tavily_api_key

LANGSMITH_TRACING=true
LANGSMITH_API_KEY=your_langsmith_api_key
LANGSMITH_PROJECT=Multi-Agent-Research
```

Keep `.env` out of Git using `.gitignore`.

## 6. Important architectural decisions

| Component | Recommended technology |
|---|---|
| AI models | OpenAI API |
| Web research | Tavily |
| Web extraction | BeautifulSoup |
| Agent framework | LangChain |
| Multi-agent workflow | LangGraph |
| Reasoning agent | ReAct |
| LLM chains | LangChain LCEL |
| Browser automation | Playwright + Chromium |
| Vector database | ChromaDB |
| Backend | FastAPI |
| Frontend | React |
| Frontend testing | Jest |
| Backend testing | Pytest |

**A few important notes:**

- ChromaDB is useful if you want semantic search over previously collected research. It is optional for a basic research workflow.
- LangGraph provides stateful multi-agent orchestration and ReAct-style agent capabilities. <Cite refs={["turn584156search2","turn584156search7"]}/>
- LangSmith helps trace and debug agent executions.
- Jest tests the JavaScript frontend; Pytest tests your Python backend.

**My recommendation:** Start with Python 3.11 or 3.12, install the dependencies, and then build the agents individually before connecting them through LangGraph. Once the project works, generate a locked dependency file with tested versions to make installations reproducible.

This gives you a solid foundation for a full-fledged multi-agent research platform.
